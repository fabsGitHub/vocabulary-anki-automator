How to Setup & Use Anki

  1. Install AnkiConnect Add-on:

    Open Anki Desktop, go to Tools → Add-ons → Get Add-ons, paste code 2055492159, and restart Anki.

  2. Enable Background Connections:

    Make sure Anki remains running in the background while you read. Our automator talks to it directly using local API signals.

  3. Run Text Capture Selection:

    Highlight any word inside your browser or workspace notes and hit your custom hotkey combo to preview and sync cards instantly.
